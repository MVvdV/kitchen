# Blueprint rollout record

- **Decision and owner** — What changed, who owns the rollout, and which shared rule it changes.
- **Learning** — Summarize the reusable finding. Leave source tickets and run evidence in the product project.
- **Approval and scope** — Link the recorded approval and state the approved operational scope.
- **Blueprint revision** — Record the exact Git revision and summarize the configuration changes.
