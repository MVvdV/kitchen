# Slice Delivery

Read the approved outcome, exact artifact revision, and acceptance criteria. Surface missing, ambiguous, or stale approval before treating proposed scope as ready for delivery. Keep a self-contained change as one ticket. Otherwise identify the smallest end-to-end outcomes that can be implemented, integrated, and verified independently. Split by observable behavior where possible.

For each slice, specify a stable key, outcome, acceptance evidence, prerequisites, and wave. Start a later wave when there is a real dependency or an outcome that needs review first. Keep unresolved scope choices visible. Return the plan for execution by the caller.
