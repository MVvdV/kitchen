# Build Change

Read the approved scope and baseline. Reuse isolation supplied by the host, or create a separate checkout if needed. Preserve unrelated changes. Add or update behavior-level checks where they materially improve proof.

Run the relevant commands and capture the candidate revision, results, and reproduction steps. Reuse a matching branch or artifact when resuming. If the work needs a material scope decision, report the choice before implementing it.
