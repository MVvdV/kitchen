# Prototype Question

Name the question and what outcome would change the design decision. Select the smallest prototype that can answer it. Include realistic inputs or an example interaction where they affect the answer.

Return the artifact, how to exercise it, what it demonstrated, and what remains uncertain. Treat production implementation as a separate decision.
