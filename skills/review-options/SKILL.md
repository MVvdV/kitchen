# Review Options

Define the decision, input revision, options, and comparison criteria. Where reviewers are available, give each the same brief and collect their first assessments before reconciling them. Ask for evidence that could change the recommendation.

Return the recommended option, tradeoffs, unresolved dissent, and unavailable evidence or perspectives. Mark the decision as advisory when another person or role holds approval authority.
