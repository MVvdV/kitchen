# Review Options

Define the decision, input revision, options, and comparison criteria. Invite reviewers with the relevant expertise who are independent of the candidate. Give them the same brief and collect first assessments before reconciling them. If a contributor provides context, label it as such. Seek another qualified reviewer when needed and record any perspective you could not obtain. Ask for evidence that could change the recommendation.

Return the recommended option, tradeoffs, unresolved dissent, and unavailable evidence or perspectives. Mark the decision as advisory when another person or role holds approval authority.
