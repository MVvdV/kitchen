# Delegate Task

Use a deterministic tool for work it can perform directly. Delegate when a task can be specified independently or benefits from a separate review. Give the helper the needed artifacts, scope and permissions, expected evidence, and stop condition. Use the least costly capable execution option available under the caller's policy.

The lead checks the result and remains accountable for integration and decisions. Record handoffs that affect the outcome so another run can resume.
