# Verification

Independently check the exact candidate against the approved acceptance criteria. Reproduce the checks from the linked revision and record commands, environment, results, and findings. If a defect requires implementation work, return the ticket to Build with evidence and explicitly hand it to the previous engineer or their available peer.

A child can reach Done after its change is integrated and verified in the agreed environment. A standalone issue that requires release goes to Prepare Release once verified. A candidate that changes needs fresh verification. A required integration result that is still pending has no passing verdict yet.
