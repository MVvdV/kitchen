# Release

In Prepare Release, record the exact candidate, required CI results, target environment, smoke checks, and rollback procedure. Before approval, use local checks and evidence in the issue. If an already published candidate has required linked CI, use one durable wait and recheck the head when resumed. Move to Approve Release after recording the evidence.

Mike explicitly approves the exact candidate SHA, destination, and GitHub actions in Approve Release. Mike may publish or name Codex as the release operator. Check the outgoing commits and publication text for automated attribution and record the published revision. A changed candidate or destination needs fresh approval. In Verify Release, check the actual deployed revision and run smoke checks against the agreed target. Record the deployment link and results. Mark Done when the release criteria pass. On failure, record the evidence and rollback path. Route agent-resolvable work to the responsible role. Mark Blocked only if a specific human action is required.
